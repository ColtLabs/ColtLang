Install Colt

One command installs the pre-built, checksum-verified native colt executable directly into your user path.

Windows PowerShell Installation

Supported architectures: x86_64. Automatically installs to %LOCALAPPDATA%\Programs\colt\bin and updates user PATH.

Run in PowerShell (Run as regular user, no Admin required):
irm https://coltlang.dev/install.ps1 | iex
ℹ What this installer does
  • Detects operating system architecture (x86_64).
  • Downloads release binary from official GitHub Releases.
  • Verifies SHA-256 integrity against published SHA256SUMS.txt manifest.
  • Idempotently adds install directory to your user PATH.
  • Executes colt version to verify installation.

Windows Command Prompt Installation

Native batch installation using curl and tar. Supported on Windows 10 & 11.

Run in Command Prompt (CMD):
curl -fsSL https://coltlang.dev/install.cmd -o install.cmd && install.cmd && del install.cmd

Note: If PowerShell is available on your system, the CMD installer automatically delegates to the PowerShell script for checksum verification and PATH registration.

macOS Installation

Universal support for Apple Silicon (M1/M2/M3/M4) and Intel x86_64 processors.

Run in Terminal:
curl -fsSL https://coltlang.dev/install.sh | sh
💡 User-Level Installation

Installs into ~/.local/bin/colt without requiring sudo or root permissions. If ~/.local/bin is not in your PATH, add export PATH="$HOME/.local/bin:$PATH" to your ~/.zshrc.

Linux Installation

Self-contained glibc x86_64 executable. Works on Ubuntu, Debian, Fedora, Arch, Alpine, and RHEL.

Run in Shell:
curl -fsSL https://coltlang.dev/install.sh | sh

Extracts binary into ~/.local/bin/colt and checks SHA-256 checksum with sha256sum.

Building from Source

Build the official native executable directly using the Rust toolchain (Rust 1.80+ required).

Terminalbash
# 1. Clone repository
git clone https://github.com/ColtLabs/ColtLang.git
cd ColtLang

# 2. Build optimized release binary
cargo build --release -p colt-cli

# 3. Verify executable
./target/release/colt version
./target/release/colt check examples/library.colt

Post-Installation Verification

Run these verified commands to confirm that Colt is installed and ready to execute queries:

Verification Workflowcolt-cli
# 1. Check version handshake
colt version

# 2. Inspect environment health and database readiness
colt doctor

# 3. Simulate execution preview without database mutations
colt run examples/library.colt --dry-run

# 4. Launch interactive terminal workspace
colt

Updating & Uninstalling

Updating to Latest

Simply rerun the installation command for your platform. The installer downloads the newest release and replaces the binary safely.

Uninstalling

Delete the colt executable from your install directory (%LOCALAPPDATA%\Programs\colt\bin on Windows or ~/.local/bin/colt on Unix).
