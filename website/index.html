Architecture

How Colt Executes Multi-Paradigm Data

Colt separates declarative language planning from database execution, ensuring deterministic execution plans, zero SQL injection, and unified access across heterogeneous backends.

💎

Declarative Language Pipeline

Source files (.colt) pass through a high-performance Rust zero-alloc tokenizer and Pratt parser into a canonical camelCase AST. Language constructs are strictly validated against catalog declarations.

🛡️

Capability & Plan Gatekeeper

The compiler enforces schema constraints, type bounds, and engine capability matrices. Queries never embed raw literal strings in query text—all parameters are strictly bound and separated.

⚡

Real Multi-Paradigm Runtime

colt run orchestrates execution through verified database adapters (Postgres, Neon, Supabase, Redis, Firestore, MongoDB) delivering structured, paradigm-aware results without mock fallbacks.

Declarative Simplicity

See Colt in Action

Compare clean, unified Colt source code with the generated backend-neutral execution plan.

examples/library.colt Colt Source 
-- 1. Connection & Collection Definitions
CONNECT main AS postgres(env("DATABASE_URL"))
DEFAULT CONNECTION main

DEFINE COLLECTION books STRICT {
  id: uuid @key,
  title: text,
  author: link<authors>,
  tags: list<text>,
  metadata: doc,
  embedding: vector(3) @index(hnsw),
  views: int @default(0)
}

-- 2. Declarative Query with Projection & Filter
FIND books SELECT title, author, metadata.edition
WHERE views > 10
ORDER BY views DESC
LIMIT 20

-- 3. Atomic Transaction
ATOMIC {
  DELETE books:33333333-3333-4333-8333-333333333333;
  PUT authors:22222222-2222-4222-8222-222222222222 {
    name: "Ursula K. Le Guin"
  }
}

Get Started

One-Command Installation

Install the native Colt executable in seconds on Windows, macOS, or Linux. No Rust toolchain or Node.js required.

Windows (PowerShell)

Recommended for Windows 10 & 11.

irm https://coltlang.dev/install.ps1 | iex

Windows (CMD)

For traditional Command Prompt environments.

curl -fsSL https://coltlang.dev/install.cmd -o install.cmd && install.cmd && del install.cmd

macOS & Linux

Universal shell installer with checksum validation.

curl -fsSL https://coltlang.dev/install.sh | sh
