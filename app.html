Programmatic Integration (Python & REST)

Query your multi-model backend directly from Python or any standard HTTP client: 

from coltanedb import ColtaneClient

client = ColtaneClient(
    api_key="clt_live_your_key_here",
    base_url="https://coltanedb.vercel.app"
)

# Run raw Colt queries with TenantGuard
res = client.query("""
    FIND books SELECT id, title, rating
    WHERE rating >= 4.5
    LIMIT 10
""")
print(res.data)
