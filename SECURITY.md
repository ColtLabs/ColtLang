# Security Policy

ColtaneDB is under active development; do not use it for production or real user data until the security requirements in the project brief are met.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not file a public issue containing exploit details, credentials, tenant identifiers, or user data. If private reporting is unavailable, contact the repository owner privately and request a secure reporting channel.

Do not include provider secrets in reports unless strictly necessary. Revoke and rotate any secret that may have been exposed, then share only the minimum evidence needed to investigate.
